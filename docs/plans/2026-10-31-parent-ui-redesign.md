## 家长打开小灯塔想做什么

打开的场景通常很短：看一眼孩子现在怎样，有申请就处理，然后关掉。所以优先级是：

1. 孩子现在在做什么，符不符合规则。
2. 有没有等我处理的事。
3. 今天什么时候开放。
4. 改规则，这件事频率低。

## 现有界面的问题

| 位置 | 问题 |
| --- | --- |
| 概览 | 四张等宽卡片，默认窗口宽度下“1 小时 13 分”会折行；待处理申请只是一个数字，下半屏空着 |
| 每周时段 | 游戏和视频各 7 行开关加时间选择，共 14 行，看不出一周全貌，也没法批量应用 |
| 临时申请 | 单独一页，家长要多点一次才能处理最紧急的事 |
| 设置 | 部署密钥、配对、番茄钟、更新、演示按钮混在一页；孩子的规则藏在“设置”里 |
| 文案 | 有开发者语言（Bundle ID、API、部署密钥）和玩笑话，不是家长的语言 |
| 配色 | 靛蓝、青、紫、蓝、橙同时出现，卡片套边框，和全局界面规范不符 |

## 参考

| 产品 | 借鉴什么 | 不借鉴什么 |
| --- | --- | --- |
| Google Family Link（主参考） | 同样是家长远程管理加孩子发申请，把使用情况、限额和请求集中到高频入口 | 手机端标签页结构，位置追踪 |
| Mac 上的屏幕使用时间（平台参考） | 侧边栏加分组设置，时段可以每天相同或按天不同 | 依赖家人共享账号，功能项过多 |
| Nintendo Switch 家长控制（语气参考） | 只说几件事；到时间是提醒还是强制停止，让家长明确选择 | 只针对游戏机的玩法 |

借鉴的是结构和做法，界面是原创设计，没有复制这些产品的视觉。

## 方案

导航从“概览 / 每周时段 / 临时申请 / 设置”改成“今天 / 规则 / 记录 / 设备”。

| 新页面 | 内容 |
| --- | --- |
| 今天 | 孩子状态、待处理申请（可直接批准）、今天的时段轴、最近发生的事 |
| 规则 · 时段 | 一周视图，亮起来的是允许时段，点一下就能改，可应用到工作日 |
| 规则 · 休息与护眼 | 番茄钟三种模式、每日提醒、坐姿提醒，从“设置”移过来 |
| 规则 · 应用与网站 | 原“家长分类覆盖”，换成家长听得懂的说法 |
| 记录 | 30 天事件，这轮没有画，先用“今天”页的列表代替 |
| 设备 | 孩子 Mac 状态、配对、更新；服务地址和重选角色收进“高级” |
| 菜单栏 | 不打开主窗口就能批准申请 |

视觉：黑灰为主，灯塔的暖黄光是唯一点缀色，只表示“这段时间开放”。不用彩色图标底，不用卡片套边框。

## 实现结果

| 内容 | 实际做法 |
| --- | --- |
| 状态文字和开放时段 | 由规则和已批准的申请算出来，放在 `LittleBeaconCore`，有单元测试，并和 `RuleEvaluator` 对照过 |
| 时段轴 | 默认从 06:00 开始；如果有更早的规则，轴会自动往前扩，不会藏掉时段 |
| 一周视图 | 每天编辑一段；旧数据有多段时全部显示，修改时提示会合并。可精确到分钟 |
| 批量设置 | “应用到工作日”只算一次规则变更，只上传一次 |
| 设备页 | 只显示“孩子的 Mac”、在线状态和同步时间，**不显示**孩子 Mac 的型号和版本，因为同步里没有这些数据 |
| 应用例外 | 分“网站 / 应用”两种。应用可以从这台 Mac 上选，也可以手填标识。列表里能查到名字就显示名字 |
| 菜单栏 | 家长端是窗口式面板，孩子端保持原来的普通菜单 |
| 事件说明 | 只说记录里有的事。没有强制结束时写“提醒 2 次，持续 1 分 15 秒”，不写 demo 里的“孩子自己离开”，因为事件记录不能证明这一点 |
| 主题色 | 文字和底色跟随系统，深色模式下也能用；暖黄固定 |

和 demo 的差别：删除了只用于开发的“添加演示事件”按钮；孩子端界面这次没有改。

## 以后要决定的事

- 要不要让每天设置多段时段。规则模型支持，界面目前每天一段。
- 孩子 Mac 的名称和版本要不要同步到家长端。
- 孩子端要不要也换成这套风格。

## 验证情况

已验证：

- 单元测试：Swift、后端、类型检查全部通过（数量见 PR）。
- 打包通过。
- 实际应用渲染：今天、规则三个子页、记录、设备，覆盖 980×700；今天和规则页还看了最小窗口 820×600。
- 实际运行时，家长端菜单栏只出现一个图标。

没有验证，需要人工确认：

- **点开菜单栏面板。** 这台 Mac 的菜单栏图标太多，自动点击点不到小灯塔图标。面板只看过渲染图。
- **主窗口里实际点按钮。** 全屏空间和台前调度让自动化够不到窗口。按钮背后的逻辑有单元测试，点击这一步没有测。
- 连接真实服务时的批准流程。
- 深色模式下的观感。
- 没有找真实家长试用。
