# 孩子端在后台运行，退出需要家长管理员密码

孩子端配对后切换为菜单栏应用：没有 Dock 图标，登录后不弹窗口，窗口从菜单栏打开，关窗不影响运行。正常退出请求都先经过 `applicationShouldTerminate`，由 macOS 的系统弹窗验证 `system.privilege.admin`，通过才退出；取消或失败时继续运行。活动强制休息期间仍直接拒绝退出。

家长密码选择这台 Mac 的管理员密码，而不是新增一套应用内密码。ADR-0005 已经约定家长持有管理员权限，孩子使用标准账户；系统弹窗负责验证，应用看不到也不保存密码，断网时同样可用，后端和规则同步都不需要改动。若把一个可离线校验的密码哈希同步到孩子 Mac，孩子账户能读到的文件里就会多出一份可以离线破解的材料。

保留菜单栏图标是有意的取舍：这个产品的前提是孩子知道规则在运行（ADR-0009），孩子也需要入口申请临时使用。完全隐藏会把它变成隐蔽监控，不在产品范围内。

注销、重启和关机不需要密码，也不受活动强制休息阻止，未完成的休息已经持久化，下次登录恢复。Sparkle 更新在 `updaterWillRelaunchApplication` 中放行，避免孩子端更新时要家长输入密码。提醒从主窗口内的覆盖层改为独立浮动面板，因为后台运行时通常没有打开的窗口。后台运行时持有活动断言，避免 App Nap 拉长 1 秒一次的规则检查。

这个边界仍然只针对标准账户下的普通界面路径。如果孩子账户本身是管理员，孩子自己的密码也能通过验证。强制结束进程由 LaunchAgent 恢复，主动的终端对抗不在保证范围内。
