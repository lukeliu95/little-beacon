# 上学时段只做护眼提醒，其他都不管

家长可以开启“上学时段”，默认工作日 8:00–18:00，星期和起止时间可改。时段内孩子端只做 25 分钟温和护眼提醒，其他都不管；时段外照原来的规则提醒和管控。

| 功能 | 上学时段内 |
| --- | --- |
| 25 分钟护眼提醒 | 保留。家长选了强制休息也降为温和提示；家长关掉了就不提醒 |
| 时段外提醒、三次提醒、结束游戏或关标签页 | 不做 |
| 快结束提醒、收尾时间、再玩 5 分钟 | 不做 |
| 违规事件、通知家长 | 不产生 |
| 每日用机时长和每日用机提醒 | 不计入、不提醒 |
| 坐姿距离提醒 | 不做 |
| 家长手动远程关闭和锁定 | 照常。这是家长自己的操作，不是自动管控 |
| 当前状态 | 照常上报，家长端会写“上学时段在玩游戏” |

进入上学时段时，正在进行的违规过程立即结束，不再等五分钟。离开上学时段时如果孩子正在用时段外的游戏或视频，按“时段外打开”处理：先提醒，60 秒缓冲后才记违规，和 ADR-0003、ADR-0013 的流程完全一样，不另加规则。上学时段和游戏允许时段重叠时，上学时段优先。

判定只有一个纯函数 `SupervisionPlan(rules:at:)`，按规则里的家庭时区计算，孩子端每秒问一次。设置存在 `RuleSet.schoolQuietHours`，老规则没有这个字段时按关闭处理，老用户升级后行为不变。后端把它列入“老客户端整份上传时要保留”的字段。

不做的事：自动识别节假日和寒暑假，第一版由家长手动关掉开关；跨午夜的上学时段。
