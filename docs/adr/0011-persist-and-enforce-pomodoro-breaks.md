# 强制番茄钟使用独立可恢复 session 和多屏前台遮罩

家长可以在关闭、温和提醒与强制休息之间明确选择；旧 `pomodoroEnabled` 只迁移到关闭或温和模式，不会静默扩大约束。

强制模式把工作计时、等待确认、确认后 5 分钟和可关闭阶段建模为独立纯状态机。状态先原子写入版本化 session，再执行遮罩或声音副作用；主文件损坏时只使用仍可解码的 last-known-good。未完成 session 不属于远程规则，也不因断网、规则改动、进程重启或主窗口关闭而消失。

前台提示由每块 `NSScreen` 对应的公开 AppKit screen-saver 层级无边框面板承载。活动 session 中取消普通终止，孩子端菜单不提供隐藏和退出。警报使用 App 自带音频，等待确认期间每 30 秒重复；确认后停止，5 分钟到点只提示一次，遮罩仍需用户主动关闭。

这个决定保证的是标准孩子账户中的正常图形界面和应用生命周期，不覆盖登录窗口、锁屏、关机、安全模式、管理员、MDM 或主动终端篡改。更强对抗需要特权 helper 或设备管理，普通 App 不在窗口层级上戴一顶纸皇冠就宣布自己成了操作系统。
