# 摄像头画面只在孩子 Mac 短暂处理

坐姿距离提醒默认关闭。家长可以通过家庭规则设置检查间隔和最低安全距离，但孩子端仍须明确授予
macOS 摄像头权限，并在当前摄像头前完成一次本机校准；远程规则不能绕过系统授权或替孩子完成校准。

每次检查只在孩子正在使用电脑时短暂启动内置摄像头，通过 Vision 检测连续多帧中唯一一张正脸的
归一化脸框宽度，并与本机校准值比较。普通单目摄像头无法提供可靠的绝对深度，因此产品只把结果
表达为“距离合适”“距离过近”或“无法判断”，不承诺精密厘米测量。无人脸、多人、低置信度、
摄像头忙碌或设备变化一律视为无法判断，不能转成违规或告警。

原始帧、照片、录像、人脸特征、身份模板和逐次距离记录都不写入磁盘，也不发送给家长端或远程服务。
本地只保存摄像头标识、归一化脸框比例、参考距离与校准时间。摄像头改变后旧校准立即失效。这一选择
牺牲了远程查看、历史分析和部分测距精度，以保住透明、最小化且能向孩子讲清楚的隐私边界。
