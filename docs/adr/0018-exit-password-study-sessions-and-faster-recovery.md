# 孩子端用家长设的退出密码退出，学习时段完全安静，自动恢复 5 秒内拉起

来源：issue #19，方案见 `docs/specs/2026-11-26-exit-password-watchdog-study-sessions.md`。

## 退出密码（修改 ADR-0016 的“配对后不能退出”）

家长在家长端“设备”页设置一个小灯塔自己的退出密码，不是电脑的密码。规则里只存加盐的 PBKDF2-SHA256 校验值（20 万次），随规则同步到孩子端，孩子端离线也能核对。配对后的孩子端：

| 情况 | 结果 |
| --- | --- |
| 家长设了密码，孩子输对 | 保存状态后卸下本次登录的后台服务（`launchctl bootout`），再退出；下次登录照常启动 |
| 输错 | 继续运行；连续错 5 次锁 1 分钟 |
| 家长没设密码 | 弹出说明后继续运行 |
| 输入时开始了强制休息 | 不退出，后台服务保持 |

配对前仍用 Mac 管理员密码。注销、关机、更新照常放行。家长清除密码时规则里写 `null`，后端按“明确清除”保存，只有缺这个字段的旧客户端上传才会被补回。

## 学习时段

家长添加的一次性时段（从现在起 1/2/3 小时，或指定开始和结束），单段最长 12 小时，最多 20 段。时段内 `SupervisionPlan` 把护眼提醒也关掉，其余和上学时段相同：不管时段、不记违规、不通知、不算用机时长、不做坐姿检查；家长的远程关闭照常。学习时段和上学时段重叠时按学习时段。

## 自动恢复修正

在孩子 Mac 上 0.10.0 的安装命令装完后，孩子端被结束却没有回来。查到四处原因并都已修正：

1. 由后台服务启动的孩子端，启动时在准备休息提示音的地方会卡住一分钟左右（CoreAudio 连接等待），这期间没有菜单栏图标，也不执行规则。提示音改为后台加载，加载完之前要响就用系统提示音。用隔离副本在这台 Mac 上复现并确认修好。
2. 后台服务接手时，等待旧副本结束的方式从“转主线程循环”改为直接等进程消失，不在 App 初始化阶段转主循环。
3. 系统默认被结束 10 秒后才重启，配置加上 `ThrottleInterval = 5`。只有带这一项的配置才显示“自动恢复已开启”。
4. 安装脚本先启用、等旧服务真正停下再注册，失败就明说；最后自动结束一次孩子端，确认它回来。脚本自带配置，可以用一行 `curl … | zsh` 运行；在家长端运行会被拒绝。

另外，孩子端发现“后台服务已安装，但自己不归它管”（比如更新后被普通方式打开，或服务被卸下），会在 30 秒内把服务注册或启动起来，由服务那一份接手。

## 边界

和 ADR-0009、ADR-0016 相同：只保证标准账户下的普通界面路径。孩子在终端里对自己会话执行 `launchctl bootout` 后，在下次登录前不会回来；退出密码的校验值在孩子 Mac 上，4 位纯数字可以被懂技术的人离线猜出，建议家长用 6 位以上。
