# 小灯塔：第一版产品简报

## 目标

小灯塔是一款透明运行的 macOS 家庭规则工具。它判断孩子是否在非允许时段玩游戏或看视频，先提醒孩子自行离开，在三次提示后终止仍持续的违规活动，并把必要事件通知家长。它不记录屏幕、按键、聊天内容或完整浏览历史。

## 第一版范围

- 一个原生 macOS 应用，最低支持 macOS 14 Sonoma。
- 首次启动选择家长端或孩子端，服务器凭据决定实际权限。
- 一台家长 Mac 与一台孩子 Mac 配对。
- 孩子使用标准 macOS 账户，家长持有管理员权限。
- Safari 与 Google Chrome 支持前台域名分类；其他浏览器不承诺识别视频。
- 家长端暂不支持 iPhone。
- 可选坐姿距离提醒只在孩子端明确授权、完成本机校准后运行。

## 家庭规则

- 游戏与视频使用彼此独立的每周重复允许时段。
- 同一天可以设置多个允许时段。
- 产品内置常见游戏、视频应用和视频网站分类清单。
- 家长可以把任意应用或域名覆盖为游戏、视频或忽略；家长覆盖优先于内置清单。
- 孩子可以申请游戏或视频的 15、30、60 分钟临时许可；家长批准后立即生效，到期自动恢复周计划。

## 活动判断

- 只判断屏幕最前方的实际活动；后台运行、下载、更新、暂停或仅保持打开不计入活动。
- 浏览器只读取当前前台标签页的规范化域名，分类后不保留完整网址、标题、标签列表或历史。
- 普通合规活动不形成历史记录。
- 家长端显示一张持续覆盖的当前状态卡：在线或离线、最后同步时间，以及游戏、视频、其他或空闲。

## 坐姿距离提醒

- 家长可以开启或关闭提醒，并设置 5～60 分钟的检查间隔和 30～80 厘米的最低安全距离。
- 孩子端必须单独授予 macOS 摄像头权限，并在设定距离完成一次本机校准；规则同步不能代替这一步。
- 检查只在孩子正在使用电脑时短暂启动内置摄像头，使用多帧人脸框比例判断是否明显过近。
- 普通 Mac 摄像头不提供可靠的绝对深度，因此界面以“安全”或“过近”为主要结论，不把估算厘米数描述成精密测量。
- 无人脸、多人入镜、光线不足、摄像头被占用或摄像头发生变化时，不产生过近提醒。
- 摄像头帧只在本机内存中处理，不拍照、不录像、不上传；校准只保存摄像头标识、归一化脸框比例、参考距离和时间。

## 提醒与升级处置

发现不合时段的前台活动后：

1. 第 0 秒：孩子端第一次提示。
2. 第 60 秒：孩子端第二次提示，生成违规事件并通知家长。
3. 第 120 秒：孩子端最终提示。
4. 第 180 秒：若违规仍持续，结束当前游戏应用，或只关闭当前违规浏览器标签页。

短暂切到合规活动只暂停计时；连续五分钟没有任何违规前台活动才重置整个违规过程。游戏与视频之间切换仍属于同一违规过程，提示次数继续累计。

孩子端可见、没有普通退出入口、登录后自动启动，异常退出后自动恢复。卸载或修改受保护配置需要家长管理员权限。第一版不宣称具备企业 MDM 级防绕过能力。

## 离线与可靠性

- 孩子端保存最后一份有效规则，本地独立完成分类、计时、提示和升级处置。
- 断网不会停止规则执行。
- 断网产生的事件进入本地待同步队列，恢复网络后按原始发生时间提交。
- 远程服务故障只延迟家长同步，不影响孩子端规则生效。

## 事件与隐私

违规事件只记录：

- 活动类别；
- 应用名称；
- 视频站点的规范化域名；
- 开始时间与持续时间；
- 提示次数；
- 是否执行升级处置。

事件保留 30 天，随后从家长端、本地缓存和远程数据库自动删除。系统不记录截图、摄像头照片或录像、按键、聊天内容、完整网址、页面标题或普通合规活动历史。

## 远程架构

- Vercel Functions 提供 HTTPS API。
- Neon Postgres 保存家庭、设备、规则、状态、申请和违规事件。
- Mac 客户端不直接连接数据库，也不持有数据库凭据。
- 家长端每 30 秒轮询新增事件和临时申请，并产生本地系统通知。
- 首次部署使用 Vercel 环境变量中的部署密钥建立家长身份。
- 家长生成十分钟有效、限制尝试次数且单次使用的六位配对码。
- 孩子端以配对码换取权限受限的设备凭据；客户端凭据保存于 macOS 钥匙串。

## 当前交付约束

- 开发机具备 macOS 26.5.1、Xcode 26.6 与 Swift 6.3.3。
- 当前没有 Apple Developer Program 签名身份。
- 第一版使用自建 Vercel API，不依赖 CloudKit 或 Apple 推送。
- 本地开发包可以构建和测试，但对外分发前仍需要 Apple Developer 签名与公证，或在家庭设备上采用明确的手动安装流程。
