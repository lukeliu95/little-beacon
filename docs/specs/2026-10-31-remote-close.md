# 家长远程关闭游戏和浏览器方案

- 日期：2026-10-31
- 状态：Luke 已放行，三项决定都按推荐走（1B、2A、3A）
- 决定记录：`docs/adr/0014-parents-can-close-apps-remotely.md`
- 验收记录：`docs/reviews/2026-10-31-remote-close-verification.md`

## 这件事为谁解决什么

| 角色 | 在意什么 | 我们能给什么 |
| --- | --- | --- |
| 家长 | 不在孩子旁边，也能让孩子现在停下，不用当面吵 | 点一下，孩子的 Mac 自己提醒并关闭，结果回到家长端 |
| 孩子 | 不想被突然关掉、丢存档 | 先说清是家长要求的，留时间存档 |

现在的瓶颈：关闭动作只由规则触发。**孩子在允许时段内，家长没有任何办法让他现在停下。**

## 现状

| 项 | 现在怎样 | 对这个功能的影响 |
| --- | --- | --- |
| 关闭游戏 | 只结束最前面的应用，退出请求发出就算成功（`ActivityMonitor.swift:43`） | 要关全部同类，并核对真的退出了 |
| 关闭浏览器 | 只关 Safari、Chrome 当前标签页，依赖自动化权限 | 改成退出整个浏览器 |
| 识别游戏 | 内置清单 7 个应用 ID，其中 4 个是启动器（Steam、战网、Epic、Minecraft 启动器） | 从 Steam 启动的游戏、Minecraft 本体很可能算“其他”，会关不到。见决定 3 |
| 家长看到什么 | 只有游戏、视频、其他、空闲四种状态 | 看不到浏览器开没开，所以孩子端要回报结果 |
| 家长到孩子的通道 | 孩子每 30 秒拉一次，没有推送 | 最多约 30 秒才开始执行 |
| 家长端 | 只有 Mac，没有 iPhone | “远程”只限家长手边有 Mac |

## 参考

| 来源 | 做法 | 对方案的影响 | 证据强度 |
| --- | --- | --- | --- |
| [Apple 屏幕使用时间](https://support.apple.com/guide/mac-help/mchl10157962/mac) | 家长打开停用时间时，孩子会收到“5 分钟后开始”的通知 | 关闭前要告诉孩子，并留收尾时间 | 官方说明 |
| [Family Link](https://support.google.com/families/answer/7103340?hl=en) | 家长可远程锁定、解锁设备；设备快被锁时通知孩子 | 同上；提前多久、离线怎么办，页面没写 | 官方说明 |

这两家是锁整台设备。小灯塔按 ADR-0003 不锁电脑，孩子可能在写作业，所以只关指定的应用。

## 方案

### 流程

| 时刻 | 家长端 | 孩子端 |
| --- | --- | --- |
| 点按钮 | 确认一次，写清会发生什么 | |
| 最多约 30 秒 | “已发给孩子的 Mac” | 屏幕中央提示加提示音：“家长让你现在结束游戏，1 分钟后关闭，记得存档” |
| 1 分钟后 | | 先正常退出，10 秒没退再强制退出 |
| 再过几秒 | “已关闭 Roblox”“没有打开的游戏”或“有 1 个没关掉” | “游戏已关闭” |
| 5 分钟没回应 | “孩子的 Mac 没有回应，可能离线或还没升级” | 命令作废，之后上线也不执行 |

### 关什么

| 按钮 | 关闭 | 不碰 |
| --- | --- | --- |
| 关闭游戏 | 所有正在运行、被判为游戏的应用，包括家长自己设为游戏的，不管在不在最前面；前台被判为游戏的浏览器标签页 | 视频应用、其他应用 |
| 关闭浏览器 | 清单里的浏览器整个退出：Safari、Chrome、Edge、Firefox、Arc、Brave、Opera、Vivaldi | 清单外的应用、系统应用、小灯塔自己 |

浏览器用固定清单，不靠“能打开网页”来判断，避免误关别的应用。Edge、Firefox 这些现在识别不了视频的浏览器，这次也能关。

按钮放在家长端“今天”页和菜单栏面板。孩子的 Mac 离线时按钮不可点，并写明离线。

### 特殊情况

| 情况 | 处理 |
| --- | --- |
| 孩子的 Mac 休眠或断网 | 5 分钟后过期，不补执行，防止第二天突然被关 |
| 1 分钟内孩子自己关了 | 到点没东西可关，回报“孩子已经关了” |
| 正在强制休息 | 不再弹提示，到点照常关 |
| 家长连点 | 同一目标只保留一条 |
| 在收尾时间或“再玩 5 分钟”里 | 家长的命令优先 |
| 孩子端重启 | 已收到的命令保存在本地，重启后继续 |

## 要你定的

### 1. 关闭后孩子能不能马上重新打开

| 选项 | 做法 | 问题 |
| --- | --- | --- |
| A | 只关一次 | 在允许时段内，孩子几秒后就能重新打开，等于白关 |
| **B（推荐）** | 关闭时选锁多久：不锁、30 分钟、1 小时、今天。可随时解除。锁定期间打开，5 秒内提示并关闭 | 多一份本地锁定状态和一个解除动作 |

选 B 时，锁定优先于时段、临时许可和“再玩 5 分钟”，断网也生效。解除要等孩子的 Mac 下次同步。

### 2. 关之前给多久

| 选项 | 做法 | 问题 |
| --- | --- | --- |
| **A（推荐）** | 固定 1 分钟 | 加上同步，最长约 1 分半才关 |
| B | 家长每次选“1 分钟”或“马上” | 多一步选择 |
| C | 收到就关 | 孩子可能丢存档，容易起冲突 |

### 3. 游戏识别不全怎么办

| 选项 | 做法 | 问题 |
| --- | --- | --- |
| **A（推荐）** | 你告诉我孩子常玩的 3～5 个游戏，我核对应用 ID 后写进清单。按了关闭却没找到游戏时，回报孩子最前面的应用名，家长可点“设为游戏并关闭” | 只有家长按了关闭才回报，但这是新的数据外传 |
| B | 只回“没有找到游戏” | 隐私最简单，但家长明知孩子在玩却关不掉 |

## 工程影响

| 内容 | 影响 |
| --- | --- |
| 后端 | 新表 `remote_commands`；新增 1 个接口 `api/commands`，家长创建、孩子回报；`sync/child`、`sync/parent` 各多一个字段 |
| 权限 | 只有家长凭据能创建命令，孩子凭据只能回报自己设备的结果 |
| 接口数量 | 现在 11 个，加 1 个是 12 个。Vercel 现行文档写“按框架而定”，旧文档写免费版上限 12 个，所以不加第 2 个 |
| 孩子端 | `LittleBeaconCore` 新增命令状态和目标判断，全部可测试；App 层负责关闭和核对退出 |
| 家长端 | 按钮、确认框、结果显示；发出后每 5 秒刷新一次，直到有结果，最多 3 分钟 |
| 记录 | 记录页多一类“家长关闭”，保存目标、时间、结果和被关的应用名，30 天删除。不存网址、标题、标签 |
| 文档 | 新增 ADR-0014：家长可以跳过三次提醒，直接要求结束。更新产品简报 |
| 费用 | 不调用收费接口。每按一次，家长端最多多约 36 次请求 |

顺带修：现有“结束活动”也核对应用真的退出了，否则记录里的“已结束”可能并没有真的结束。规则触发的结束只请求退出，不强制；只有家长发起的关闭才强制。

## 上线顺序

每一步都等你说：

1. 在生产数据库建新表。
2. 部署后端，同时带上 PR #9 还没部署的保护。
3. 发新版，家长端和孩子端都要升级。

旧版孩子端会忽略新字段，命令过期后家长端显示“没有回应”。

## 验收

| 层 | 内容 |
| --- | --- |
| 单元测试 | 目标判断、过期、重复命令、结果回报、特殊情况；后端权限和家庭隔离 |
| 测试副本 | 这台 Mac 是真实家长端，所以不碰真实浏览器，用假游戏和假浏览器走完整流程 |
| 孩子 Mac 真机 | 真实 Safari、Chrome 和孩子常玩的游戏；断网、休眠、标准账户 |

## 明确不做

| 不做什么 | 理由 |
| --- | --- |
| 锁屏、关机 | ADR-0003 已定不锁电脑 |
| 只关一个标签页 | 你要的是关闭浏览器；违规流程里关标签页的做法不变 |
| 关闭任意应用、查看孩子的应用列表 | 超出隐私边界 |
| 关闭视频应用 | 这次只做你说的两类 |
| iPhone 家长端 | 是另一件事 |
| 推送通道 | 30 秒够用 |

## 没有验证

| 问题 | 影响 |
| --- | --- |
| 退出别的应用在孩子标准账户下会不会弹授权 | 会弹的话，孩子能拒绝。要在孩子 Mac 上实测 |
| 退出 Steam 时，里面的游戏会不会一起退 | 决定“关闭游戏”对 Steam 游戏有没有用 |
| 浏览器强制退出后的表现 | 下次打开可能提示恢复标签页，未保存的表单可能丢 |
| 孩子断网 | 收不到命令。已生效的锁定不受影响。这不是企业级防绕过 |

## 要你判断的地方

- 给孩子看的话，语气够不够好。
- 1 分钟够不够孩子存档。
- 锁定时长的几档合不合适。
