# 强制 25+5 分钟番茄钟 SPEC

- 状态：Implemented for v0.6.0，发布验收中
- 日期：2026-08-02
- 适用端：孩子 Mac
- 规则管理端：家长 Mac

## 1. 目标

孩子连续使用电脑达到 25 分钟后，小灯塔立即播放警报声，并在所有显示器最前方显示不可普通关闭的全屏休息提示。

提示刚出现时只显示“确认”。用户点击确认后，进入 5 分钟强制休息；这 5 分钟内不显示关闭按钮。满 5 分钟后才显示“关闭并开始下一轮”。系统不自动替用户确认，也不自动关闭：

- 一直不点确认，提示就一直留在最前方；
- 点了确认但不点关闭，提示也继续留在最前方；
- 只有完成“确认 → 等满 5 分钟 → 主动关闭”这条路径，遮罩才消失。

讲白了，这个按钮没有“我假装没看见”分支。它可以晚点被点，但不能被剧情杀。

## 2. 产品决定

### 2.1 不偷换旧功能

当前版本已经有一个默认开启、可一键关闭的温和 25 分钟提醒。升级后不能把已有家庭的温和开关偷偷改造成强制遮罩。

规则改为三态：

| 模式 | 行为 |
| --- | --- |
| `off` | 不运行 25 分钟提醒 |
| `gentle` | 保留当前温和提醒，可立即关闭 |
| `enforced` | 启用本 SPEC 的 25+5 分钟强制休息 |

兼容规则：

- 旧规则 `pomodoroEnabled=false` 迁移为 `off`；
- 旧规则 `pomodoroEnabled=true` 迁移为 `gentle`；
- 家长必须在设置页明确选择“强制 25+5 分钟休息”才能启用 `enforced`；
- 旧孩子端看不懂 `pomodoroMode` 时，后端必须保留该字段，不能被旧上传覆盖掉；
- 一次强制休息已经触发后，家长远程改成 `off` 或 `gentle` 只影响下一轮，不能撤掉当前遮罩。

### 2.2 “5 分钟”从确认时开始

强制休息截止时间为：

`closeAvailableAt = acknowledgedAt + 5 minutes`

提醒出现到用户确认之间的等待不算进这 5 分钟。比如提醒挂了 40 分钟才点确认，很好，先恭喜这位用户在耐心上取得了某种难以评价的成就，然后仍需再等完整 5 分钟。

### 2.3 “不可关闭”的承诺边界

本功能保证：在孩子标准账户的正常图形界面和正常应用生命周期中，不能用关闭按钮、Esc、Command-W、Command-Q、隐藏 App、切换 Space、进入其他全屏 App 或关闭主窗口绕过活动遮罩。

普通 macOS App 不能保证：

- 覆盖登录窗口、锁屏、关机 / 重启确认、TCC 权限和其他系统安全界面；
- 阻止管理员、Recovery / Safe Mode、MDM、调试器或熟练终端用户强制结束 / 修改应用；
- 在设备关机、孩子退出登录或显示器断电时继续“显示”界面；
- 在系统静音、音量为零、输出设备断开或音频服务故障时强行制造可听声音。

系统重新回到孩子图形会话后，小灯塔必须恢复未完成的强制休息。若未来要求抵抗主动终端篡改，需要单独引入特权 helper 或 MDM；本 SPEC 不用普通窗口 API 冒充它们。

## 3. 术语

- **工作轮**：孩子端累计的活跃使用时间，目标为 25 分钟。
- **自然休息**：触发前连续 2 分钟空闲；沿用当前行为，重置工作轮。
- **强制休息**：工作轮完成后出现、必须确认并等待 5 分钟的前台遮罩。
- **确认**：用户明确点按“确认，我现在开始休息”。
- **可关闭时刻**：确认后满 5 分钟的绝对时间。
- **完成**：可关闭时刻到达后，用户点按“关闭并开始下一轮”。

## 4. 状态机

强制模式使用独立、可编码的纯状态机，不复用 `ChildAlert`。

| 状态 | 页面 | 允许输入 | 离开条件 |
| --- | --- | --- | --- |
| `counting` | 无强制遮罩 | 无 | 活跃累计达到 25 分钟 |
| `awaitingAcknowledgement(triggeredAt)` | 全屏遮罩；只显示确认 | 确认 | 用户点确认 |
| `requiredBreak(acknowledgedAt, closeAvailableAt)` | 全屏遮罩；显示倒计时；无关闭按钮 | 无 | 当前时间达到 `closeAvailableAt` |
| `readyToClose(closeAvailableAt)` | 全屏遮罩；显示关闭按钮 | 关闭 | 用户点关闭 |

### 4.1 工作期计时

- 只在角色为孩子端、规则模式为 `enforced`、监测开启时累计。
- 沿用现有定义：前台活动不是 `.idle` 才算活跃。
- 短于 2 分钟的空闲只暂停累计；连续空闲满 2 分钟视为自然休息，累计清零。
- 活跃累计达到 `25 * 60` 秒时，只触发一个强制休息 session。
- 强制休息未完成时，不创建第二个 session，也不继续下一轮计时。
- 从 `gentle` / `off` 切到 `enforced` 时，从新的工作轮开始，不继承旧温和计时。

### 4.2 确认

- “确认”只处理一次，重复点击必须幂等。
- 先持久化 `acknowledgedAt` 和 `closeAvailableAt`，持久化成功后才更新页面。
- 确认后停止重复警报声，页面切换为 5:00 倒计时。
- 确认不关闭窗口、不缩小窗口、不允许与其他 App 交互。

### 4.3 等待与关闭

- 5 分钟使用持久化绝对截止时间判断，不依赖数满 300 个 `Timer` tick。
- 到点前，关闭按钮根本不进入视图层级；不是灰色按钮，也不是透明按钮。
- 到点时播放一次较短提示音，并显示“关闭并开始下一轮”。
- 到点后不自动关闭。
- 关闭操作先把 session 持久化为完成 / 清除，再撤掉所有屏幕遮罩，随后开始新的 25 分钟工作轮。
- 关闭前的进程崩溃、强制结束、应用更新或系统重启，都不能把未完成 session 当成完成。

## 5. 前台遮罩

### 5.1 窗口实现

- 使用公开 AppKit API，不使用屏幕捕获、私有 API 或辅助功能注入。
- 每个 `NSScreen` 创建一个无边框、不可拖动、不可缩放、无标准关闭按钮的窗口。
- 窗口级别使用公开的 `NSScreenSaverWindowLevel` 等价层级，覆盖普通窗口、菜单栏、Dock 和常规全屏 App。
- 窗口加入所有 Spaces，并允许作为全屏辅助窗口出现；不进入 Command-Tab 的窗口循环。
- 主显示器展示完整卡片和唯一操作按钮；其他显示器展示同一状态、倒计时与“请回到主屏幕操作”，但同样拦截鼠标。
- 显示器连接、断开、排列变化后立即重建 / 调整遮罩。
- App 从后台回到前台、系统唤醒、Space 变化后重新 `orderFront`，但不使用高频抢焦点循环制造抖动。

### 5.2 不可关闭路径

活动 session 存在时：

- 不响应 Esc、Command-W 和窗口关闭请求；
- 应用代理对正常终止返回取消；
- App 菜单不提供“隐藏”和“退出”；
- 主窗口关闭、最小化或销毁不影响独立遮罩；
- Dock / Command-Tab 切换不会把遮罩降到普通窗口后面；
- 普通 `ChildAlert` 不能覆盖、替换或撤销强制遮罩；
- 角色重置、规则同步和更新检查不能清除活动 session。

### 5.3 系统界面

- 锁屏、登录、关机等系统安全界面可以显示在遮罩之上。
- 锁屏 / 睡眠前没有确认：解锁后仍停在“确认”。
- 已确认后锁屏 / 睡眠：这段时间算真实休息，达到绝对截止时间后，解锁时进入“可关闭”。
- 快速用户切换回孩子账户时恢复遮罩。

## 6. 页面内容

### 6.1 等待确认

- 标题：`该休息 5 分钟了`
- 说明：`你已经连续使用 25 分钟。先确认，然后完整休息 5 分钟。`
- 主按钮：`确认，我现在开始休息`
- 不显示关闭图标、取消、稍后提醒或跳过。

### 6.2 强制休息中

- 标题：`休息进行中`
- 大号倒计时：`04:59` 到 `00:00`
- 说明：`看看远处，喝口水，手先别急着找鼠标。`
- 不显示关闭按钮。

### 6.3 可以关闭

- 标题：`5 分钟到了`
- 说明：`休息完成。准备好以后再开始下一轮。`
- 主按钮：`关闭并开始下一轮`
- 不自动倒数关闭。

### 6.4 可访问性

- 三个页面都有明确的 VoiceOver 标题、状态、倒计时和按钮标签。
- 按钮支持完整键盘访问，但键盘只能触发当前状态允许的按钮。
- 不依赖颜色表达“还不能关闭 / 可以关闭”。
- 动效遵循“减少动态效果”；倒计时不每秒向 VoiceOver 重复播报，只在整分钟与完成时公告。
- 所有关键元素提供稳定 `accessibilityIdentifier`，供 UI 自动化验证。

## 7. 声音

- 使用随 App 打包的短警报音频资源，不依赖某台 Mac 恰好存在的系统音效名称。
- 使用被控制器强引用的 `AVAudioPlayer`，避免局部 `NSSound` 生命周期含糊。
- 进入 `awaitingAcknowledgement` 时立即播放一次。
- 未确认期间每 30 秒重复一次；页面一直显示，声音失败不改变状态。
- 点击确认后停止重复警报。
- 进入 `readyToClose` 时播放一次较短完成音。
- 不自动修改系统音量，不绕过静音，不持续占用音频会话。
- 通知权限可作为辅助提示，但通知被拒绝不影响遮罩和状态机。

## 8. 持久化与恢复

### 8.1 独立存储

强制 session 使用独立 `PomodoroSessionStore`，不和整份 `LocalSnapshot` 共存亡。至少保存：

- schema version；
- 当前模式 / 状态；
- 工作期累计活跃秒数与空闲秒数；
- `triggeredAt`；
- `acknowledgedAt`；
- `closeAvailableAt`。

写入采用临时文件 + 原子替换，并保留一份 last-known-good。状态转换 API 必须返回成功 / 失败，不能把错误吞掉。

### 8.2 顺序

- 触发：先保存 `awaitingAcknowledgement`，再展示遮罩、播放声音。
- 确认：先保存 `requiredBreak`，再停止重复声音、刷新页面。
- 完成：先持久化清除 / 完成，再撤掉遮罩。

### 8.3 恢复

应用启动时，在创建普通主窗口之前读取 session：

- `awaitingAcknowledgement`：立即重建遮罩；
- `requiredBreak` 且未到点：恢复倒计时；
- `requiredBreak` 且已到点：恢复为可关闭；
- `readyToClose`：继续显示关闭按钮；
- 主文件损坏：尝试 last-known-good，并记录可见错误；
- 两份 session 都不可读：不得静默声称休息已经完成，需要显示维护错误并保留一条可诊断日志。第一版不把这种普通损坏升级成永久锁机。

## 9. 与其他功能的关系

- 强制模式在规则已经同步到孩子端后完全本地运行；断网不停止计时、触发、确认、5 分钟等待或恢复。
- 强制休息不是违规事件，不上传屏幕、按键、音频或新的行为历史。
- 默认不向后端新增“是否确认 / 何时关闭”遥测。
- 规则违规状态机继续运行；由于遮罩成为前台活动，现有违规过程会进入合规暂停，连续 5 分钟后按原规则重置。
- 坐姿检查在强制遮罩期间暂停，避免摄像头突然亮起给休息添戏。
- 每日用机累计在屏幕锁定 / 登录窗口时不增加；强制遮罩显示期间不把小灯塔自身计成新的用机时长。
- 普通提醒在强制遮罩存在时不弹第二层窗口；必要信息可排队，遮罩完成后再展示。
- Sparkle 更新不能在活动 session 中要求应用退出；延迟到 session 完成，或由家长管理员走维护流程。

## 10. 规则与后端兼容

- 在 `RuleSet` 增加 `pomodoroMode`；Swift 解码兼容缺失字段。
- 在后端默认规则、校验、`mergeMissingRuleSettings` 和测试中加入 `pomodoroMode`。
- 新客户端上传时保留旧 `pomodoroEnabled` 作为兼容镜像，直到最低支持版本允许移除；模式真值以 `pomodoroMode` 为准。
- 孩子端只接受家长同步的模式，不提供本地关闭强制模式的设置。
- 远程规则 revision 继续遵守单调接受；活动 session 不属于远程规则文档，不能被旧规则覆盖。

## 11. 失败处理

| 故障 | 预期行为 |
| --- | --- |
| 音频资源或播放器失败 | 遮罩继续；记录错误；不伪造“已播放” |
| 通知权限被拒绝 | 无影响，遮罩仍出现 |
| 主线程短暂卡顿 | 截止时间按时钟重算，不延长 / 缩短已确认的 5 分钟 |
| App 崩溃或被强制结束 | LaunchAgent 恢复后读取 session，重建遮罩 |
| 主窗口关闭 | 独立遮罩仍在 |
| 显示器热插拔 | 新屏幕补遮罩，已移除屏幕释放窗口 |
| 家长在活动期关闭规则 | 当前 session 继续；下一轮不再触发 |
| 系统时间向后调整 | 可关闭时间不会提前；可能延后，记录时钟异常 |
| 系统时间大幅向前调整 | 使用启动时校验和允许的单调时钟证据避免无提示提前完成；重启后的管理员改时属于系统边界 |
| session 写入失败 | 不撤销当前遮罩；显示可诊断错误；重试持久化 |

## 12. 验收标准

1. 强制模式下累计 24:59 不触发，达到 25:00 只触发一个 session。
2. 触发时所有已连接显示器都被遮罩，普通 App 与常规全屏 App 不可见 / 不可交互。
3. 触发时立即有一次警报声；未确认每 30 秒重复。
4. 等待确认页面只有确认按钮，没有任何关闭路径。
5. 不点击确认，超过 5 分钟、25 分钟、1 小时后仍停留在等待确认。
6. 点击确认后才开始完整 5 分钟；4:59.999 时关闭按钮不存在。
7. 5:00 到达后才出现关闭按钮，并播放一次完成音。
8. 不点击关闭，页面永久保持可关闭状态，不自动消失。
9. Esc、Command-W、Command-Q、隐藏、主窗口关闭、切换 App / Space 均不能撤掉活动遮罩。
10. 在三个阶段分别强制结束 App；恢复后回到同一逻辑阶段。
11. 在三个阶段分别重启系统；重新登录孩子账户后回到同一逻辑阶段。
12. 确认后睡眠超过 5 分钟，唤醒后显示可关闭；确认前睡眠则仍要求确认。
13. 多显示器连接 / 断开、缩放与排列变化后没有裸露屏幕。
14. 普通提醒不能覆盖强制遮罩。
15. 强制 session 活动期收到远程 `off` 不会被撤掉；完成后不再开始新一轮。
16. 旧规则、旧本地状态和旧后端文档仍能解码；旧 `true` 保持温和模式。
17. Swift 核心、App 持久化、后端、UI 自动化和 release 打包全部通过。
18. 实机验证清单记录 macOS 14+、单屏、双屏、普通 Space 和全屏 Space 的结果。
19. 断网状态下可以完成触发、确认、等待、关闭和崩溃恢复，网络恢复后不重复触发。

## 13. 非目标

- 不锁定 macOS 登录会话，不替代屏幕使用时间、MDM 或家长控制框架。
- 不阻止管理员关机、重启、切换用户或卸载。
- 不录音、不保存声音环境、不新增摄像头行为。
- 不上传番茄钟确认历史，不做排行榜、积分或惩罚。
- 不允许家长远程替孩子点击确认或关闭。
- 本版本固定 25 分钟工作、5 分钟休息，不增加自定义时长；先把一把尺子做直，再讨论做瑞士军刀。
