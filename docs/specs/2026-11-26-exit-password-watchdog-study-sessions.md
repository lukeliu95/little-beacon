# 退出密码、自动恢复修正、学习时段

- 日期：2026-11-26
- 基线：`main` `ff98bdf`（v0.10.0）
- 来源：Luke 在孩子 Mac 上运行 0.10.0 的安装命令后，孩子端被结束了却没有自动拉起

## 一、要解决的三件事

| # | Luke 的原话 | 要做到的样子 |
| --- | --- | --- |
| 1 | 退出时要输入家长密码，不是系统密码，是软件的密码 | 家长在家长端设一个“退出密码”。孩子端退出时弹出输入框，输入和家长设的一致才能退出 |
| 2 | 修正意外关闭的守护进程，发现关闭了 5 秒后自动启动 | 孩子端被结束（强制退出、命令行结束、崩溃）后 5 秒左右自动回来。安装失败时要明说，不能显示“成功” |
| 3 | 认真学习时长时间使用，软件保持静默，家长端配置后孩子端执行 | 家长添加“学习时段”（比如今天 19:00–21:00，或从现在起 2 小时），这段时间里小灯塔什么都不提醒 |

## 二、自动恢复为什么没拉起（第 2 项的原因）

孩子 Mac 上的情况我看不到，下面是从代码和命令里能确认的几个漏洞，都会造成“装了但没拉起”：

| 漏洞 | 后果 |
| --- | --- |
| 上次给的粘贴命令，后台服务注册失败时也照样打印“已开启” | 实际没装上，却以为装好了 |
| 先移除旧服务、马上注册新服务。旧服务还没完全停下时，注册会报错失败 | 从 0.9 升上来的孩子 Mac 正好是这种情况 |
| “启用”放在“注册”之后。服务以前被停用过的话，注册会直接失败 | 同上，失败了还不提示 |
| 系统默认要等 10 秒才重启被结束的程序，测试只等了 5 秒 | 就算装好了，5 秒时去看也还没回来 |
| 孩子端被自动更新重新打开后，是普通方式打开的，不归后台服务管 | 这之后再被结束就不会回来，要等下次登录 |

## 三、方案

### 1. 退出密码

| 项目 | 做法 |
| --- | --- |
| 家长在哪设 | 家长端“设备”页，孩子 Mac 下面一行“退出密码”：设置 / 修改 / 清除。至少 4 位，输两遍 |
| 怎么保存 | 不存原文。只存加盐后反复计算得到的校验值（PBKDF2-SHA256，20 万次），随家庭规则同步到孩子端。孩子端离线也能核对 |
| 孩子端怎么退出 | 菜单栏面板里一直有“退出小灯塔…”。点它（或用活动监视器退出）弹出输入框“输入家长设置的退出密码” |
| 输对了 | 关掉孩子端，并让后台服务这一次不再拉起。下次登录时孩子端自动启动 |
| 输错了 | 提示“密码不对”，孩子端照常运行。连续错 5 次后，1 分钟内不能再试 |
| 家长没设密码 | 弹出说明“家长还没有设置退出密码，孩子端不能退出”，然后照常运行 |
| 还没配对的孩子 Mac | 维持现在的做法：输入这台 Mac 的管理员密码就能退出（配对前还没有家庭规则） |
| 注销、关机、自动更新 | 照常放行，不要密码 |

### 2. 自动恢复修正

| 项目 | 做法 |
| --- | --- |
| 5 秒拉起 | 后台服务配置加上 `ThrottleInterval = 5`：被结束后最多 5 秒重新启动 |
| 安装脚本 | 改成不依赖仓库、可以一行命令从网上下载运行。顺序改为：启用 → 移除旧服务并等它真正停下 → 注册 → 确认孩子端在后台服务下运行。任何一步失败都明说失败原因，不再显示“成功” |
| 自检 | 安装脚本最后自动做一次测试：结束孩子端，等待，确认 10 秒内回来，并打印结果 |
| 孩子端自己补位 | 孩子端发现“后台服务已安装，但自己不归它管”（比如更新后被普通方式打开、安装时注册失败）时，自己把后台服务启动起来，由后台服务那一份接手。每 30 秒检查一次 |
| 窗口底部状态 | 只有新配置（含 5 秒拉起）才显示“自动恢复已开启”。用 0.10.0 的命令装的会显示“自动恢复需要更新”，重新跑一次新脚本就好 |

### 3. 学习时段

| 项目 | 做法 |
| --- | --- |
| 家长在哪设 | 家长端“规则 → 时段”，“上学时段”下面一行“学习时段”。可以“从现在起 1 / 2 / 3 小时”一键添加，也可以选日期和起止时间。列表里能看到还没结束的学习时段，可以删除或提前结束 |
| 一段多长 | 单段最长 12 小时，最多同时存 20 段。已经结束的会在下次编辑时自动清掉 |
| 孩子端执行什么 | 学习时段内完全安静：不提醒 25 分钟休息，不管游戏和视频时段，不记违规，不通知家长，不算每日用机时长，不做坐姿距离检查 |
| 照常有效的 | 家长手动远程关闭应用；学习时段开始前已经在进行的强制休息会休息完 |
| 和上学时段的关系 | 学习时段比上学时段更安静（上学时段还保留护眼提醒）。两者重叠时按学习时段 |
| 家长和孩子看到的 | “今天”页时段图多一条“学习”；标题写“学习时段，到 21:00 小灯塔保持安静” |

## 四、兼容和上线

- 新增的两个规则字段（`childExitPassword`、`studySessions`）在旧客户端上会被忽略；旧家长端整份上传规则时，后端会保留这两个字段，不会把密码或学习时段冲掉。
- 家长清除密码时上传 `null`，后端按“明确清除”处理，不会被当成“旧客户端没带这个字段”。
- 不改数据库表。上线顺序：部署后端 → 发 0.11.0 → 孩子 Mac 升级后，跑一次新的安装命令 → 家长端设置退出密码。

## 五、已知限制（这次不做）

| 限制 | 说明 |
| --- | --- |
| 懂命令行的孩子可以自己停掉后台服务 | 后台服务装在孩子自己的登录会话里，系统允许本人停掉。要彻底防住，需要用系统级的家长控制或描述文件，超出这次范围 |
| 家长端看不到孩子端的自动恢复状态 | 状态只显示在孩子端窗口底部。放到家长端需要改数据库表，这次不做 |
| 退出密码的校验值在孩子 Mac 上 | 4 位纯数字的密码，理论上能被懂技术的人离线猜出来。建议家长用 6 位以上 |

## 六、验收

| 检查 | 怎么验 |
| --- | --- |
| 退出密码 | 单元测试：校验值正确/错误、清除、错 5 次锁 1 分钟、各种退出路径的放行与拒绝。界面：家长端设置、孩子端输入框（隔离测试副本） |
| 5 秒拉起 | 在这台 Mac 上用隔离测试副本，以单独的名字装进当前用户的后台服务，结束后计时确认 5 秒左右回来；输对密码退出后不再回来；普通方式打开的副本会把自己交给后台服务 |
| 学习时段 | 单元测试：时段边界、比上学时段优先、过期清理、非法值不生效、规则编解码。界面：规则页添加和删除、今天页的“学习”条 |
| 后端 | 新字段校验、清除密码时的 `null`、旧客户端上传时不丢字段 |
