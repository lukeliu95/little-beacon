# 家长远程关闭验收记录

- 日期：2026-10-31
- 环境：macOS 27、Xcode 27.2、Swift 6.4.2
- 方案：`docs/specs/2026-10-31-remote-close.md`
- 决定：`docs/adr/0014-parents-can-close-apps-remotely.md`

## Luke 的决定

| 问题 | 决定 |
| --- | --- |
| 关闭后能不能马上重新打开 | 关闭时选锁定时长：不锁、30 分钟、1 小时、今天，可解除 |
| 关之前给多久 | 固定 1 分钟 |
| 识别不到游戏 | 回报孩子最前面的应用名，家长可点“设为游戏并关闭”；常玩游戏补进清单 |

## 自动测试

Swift 185 条、后端 25 条全部通过。

## 端到端验证

使用临时副本，不进仓库。

| 部分 | 做法 |
| --- | --- |
| 后端 | 真实接口代码，加真实 Postgres 引擎（PGlite）和 `backend/db/schema.sql`，只替换数据库驱动 |
| 孩子端 | 打包后的应用，真实的 1 秒监测和 30 秒同步 |
| 被关闭的应用 | 四个假应用。这台 Mac 是真实家长端，所以副本只认假应用，不碰真实浏览器 |
| 前台应用 | 由测试文件决定，不抢焦点 |

40 项全部通过，主要结果：

| 场景 | 结果 |
| --- | --- |
| 权限 | 孩子凭据不能发命令（403）；没有凭据（401）；家长凭据不能回报（403）；别的家庭改不了、也收不到 |
| 连点 | 只保留一条 |
| 关闭开着的游戏 | 孩子端 28.7 秒收到，收尾时间里游戏还开着，发出到完成 89.5 秒 |
| 没有游戏 | 不打扰孩子，回报最前面的应用，没有误关 |
| 设为游戏并关闭 | 已有锁定时仍保住 1 分钟，之后关掉 |
| 不肯退出的应用 | 10 秒后强制退出，结果写已关闭 |
| 浏览器加锁 30 分钟 | 关闭，锁定 30.0 分钟；重新打开约 7 秒后被关，孩子知道原因 |
| 解除 | 送达后能打开 |
| 锁定遇到时段外 | 只有锁定提醒，没有违规提醒；孩子切走也躲不开 |
| 收尾时间里重启 | 按原时间关闭 |
| 孩子的 Mac 离线 | 家长看到没有回应，之后上线也不执行 |

## 家长端界面

在测试副本里用真实的点击事件走完一遍：点“关闭游戏”、确认、等结果、点“解除”。两端状态一致，解除后孩子端锁定清空、待传回报为 0。看过的页面：今天页的确认面板、等待、结果、锁定和解除，记录页，菜单栏面板。

## 独立审查

另一个 agent 只读审查了改动。安全和隔离没有发现问题。修掉的问题：

| 问题 | 改法 |
| --- | --- |
| 网页游戏切走后被说成“孩子已经自己关了” | 新增结果“没能确认”，不再猜 |
| “设为游戏并关闭”时，已有锁定抢走孩子的 1 分钟 | 关闭进行中时，锁定先等它 |
| 回报排在事件后面，会被一条坏事件挡住 | 回报先发；服务器拒收的事件不再挡住后面的 |
| 规则触发的结束也会强制退出 | 只有家长发起的关闭才强制，规则照旧只请求退出，并核对结果 |
| 网页游戏的域名存进了服务器 | 改存“Safari 里的网页游戏”，不存域名 |
| 23:59 按“今天”，过零点才关，锁了第二天一整天 | 按收到命令的那天算 |
| 关闭失败时孩子仍看到“已关闭” | 只有真的关了才这样说 |
| 关闭进行中强制休息开始，提醒盖在休息遮罩上 | 休息中不再弹 |
| 一条不认识的命令让同一批命令全部丢掉 | 逐条解析 |

## 查出的 0.8.0 线上问题

“再玩 5 分钟”的记录提醒次数是 0，线上服务器只收 1～3，会回 400，于是：

- 家长看不到这条记录。
- 孩子端每次同步都报错，显示“离线，稍后重试”。
- 排在它后面的违规事件可能传不上去。

这次改了后端校验，客户端也不再被拒收的事件挡住。要部署后端才生效。0.8.0 的孩子端不用升级，后端部署后积压的记录会自动传上去。
