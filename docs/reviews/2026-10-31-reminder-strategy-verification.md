# 提醒策略与孩子端验收记录

- 日期：2026-10-31
- 环境：macOS 27、Xcode 27.2、Swift 6.4.2
- 方案：`docs/specs/2026-10-31-child-ui-and-reminder-strategy.md`

## Luke 的决定

| 问题 | 决定 |
| --- | --- |
| 提醒怎么和时段结合 | 一个默认策略，单个时段可以单独指定 |
| 温和模式 | 只提醒和通知家长，不结束活动 |
| 再玩 5 分钟 | 做。温和每天 2 次，标准 1 次，严格没有 |
| 收尾时间 | 不算违规 |
| 老用户默认 | 标准 |

## 真实运行测试

使用临时副本，不进仓库。副本把收尾时间压缩成秒，把所有前台活动当作游戏，不真的结束程序。提醒在后台渲染并记录，没有显示在屏幕上。四个场景同时运行完整的监测循环，核对日志和保存的事件。

| 场景 | 实际结果 | 事件 |
| --- | --- | --- |
| 严格 | 屏幕中央提示、到点提示加语音、收尾结束后结束活动并全屏提醒 | 提醒 3 次，已结束 |
| 标准 | 角落小提示、菜单栏倒计时、到点提示带“再玩 5 分钟”、屏幕变暗、结束活动 | 提醒 2 次，已结束 |
| 温和 | 角落小提示、到点角落提示带“再玩 5 分钟”、全屏提醒，不结束活动 | 提醒 2 次，未结束 |
| 标准 + 再玩 5 分钟 | 到点后加时成功，之后没有重复提醒，也没有结束活动 | 记录一条加时 |

这台 Mac 上有中文语音。

## 单元测试

- 新增状态机测试覆盖：结束前提醒、收尾、三种结果、中途离开、加时、重启恢复、老数据兼容。
- “当前时段”的判断和 `RuleEvaluator` 逐时对照。
- 标准模式的时段外流程和文案有测试固定，确认和旧版一致。

## 没有验证

- 提醒在真实屏幕上的显示：这轮是后台渲染。上一轮确认过中央提示小窗能显示和点击。
- 角落小提示、屏幕变暗在独占全屏游戏上的表现。
- 菜单栏倒计时的实际观感，菜单栏太满时可能被挡住。
- 语音的实际听感。
- 结束真实游戏和关闭真实标签页：这段代码没有改，但这轮测试没有真的执行。
- 真实家庭里孩子的反应。
